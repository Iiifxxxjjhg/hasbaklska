# اتحاد رغمنوف — نسخة Godot 4

هذه بداية مستقلة للعبة استراتيجية سياسية عربية ثنائية الأبعاد.

## تشغيل المشروع
1. نزّل المستودع من GitHub بصيغة ZIP.
2. فك الضغط.
3. افتح Godot 4.3 أو أحدث.
4. اختر Import ثم افتح المجلد `godot_raghmanov` الذي يحتوي على `project.godot`.
5. اضغط F6 أو زر التشغيل ▶ لتشغيل اللعبة.

## الموجود في النموذج الأولي
- خريطة سياسية تخطيطية تفاعلية بثلاث جمهوريات قابلة للاختيار.
- مؤشرات الخزانة والاستقرار والتأييد والجاهزية العسكرية.
- قرارات رئاسية تغيّر المؤشرات.
- أدوار متتابعة وسجل أحداث.
- توصيات مستشارين مبنية على حالة المؤشرات، وليست ذكاءً اصطناعيًا متصلًا بالإنترنت بعد.

## ملاحظة
الخريطة الحالية شكل تخطيطي تجريبي وليست خريطة جغرافية نهائية. المشروع لا يحتاج إلى مفتاح API أو خدمة مدفوعة.
